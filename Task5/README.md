[**3100. Water Bottles II**](https://leetcode.com/problems/water-bottles-ii/)

**Difficulty:** $\textcolor{#ffaa00}{\textsf{medium}}$

Чтобы выпить как можно больше бутылок воды, как только пустых бутылок становится достаточно для обмена (`emptyBottles == numExchange`), необходимо менять пустые бутылки на полную.

Я завела переменную `emptyBottles` для хранения текущего количества пустых бутылок и `drunkBottles` для хранения общего количества выпитых бутылок. 

Цикл while выполняется при любом из двух условий - еще остались полные бутылки, или же количества пустых бутылок достаточно для обмена. 

Если пустых бутылок не хватает для обмена, мы выпиваем одну бутылку, при этом у нас появляется одна пустая бутылка и общий счетчик выпитого инкрементируется. Если пустых бутылок достаточно для обмена - осуществляем обмен. Пустых бутылок становится 0, полных бутылок становится больше на 1, и, из условия задачи, требуемое количество бутылок для успешного обмена увеличивается на 1. 

Таким образом, мы получаем наибольшее возможное количество выпитых бутылок (`drunkBottles`).
