[**Problem 75. Sort colors**](https://leetcode.com/problems/sort-colors/)

Для решения задачи я завела три указателя. `leftPtr` хранит индекс массива, по которому можно записать число ноль. `rightPtr` хранит индекс массива, по которому можно записать 2. `searchingPtr` - "ищейка", с помощью которой мы проходимся по массиву и сортируем его, отправляя нули влево, а двойки вправо. Если `searchingPtr` нашел ноль, то меняем значения по индексам `searchingPtr` и `leftPtr` местами, а затем инкрементируем обе переменные, чтобы продолжать сортировку. Похожая логика применяется при нахождении двойки, - меняем местами значения по индексам `searchingPtr` и `rightPtr`, но, чтобы продолжать сортировку, декрементируем `rightPtr` (чтобы находиться в пределах границ массива). `searchingPtr` не трогаем, так как уже после свапа по этому индексу может оказаться 0, который нужно будет отправить влево. В противном случае, если `searchingPtr` найдет единицу, то просто проследует дальше. Цикл завершится, когда `searchingPtr` встретится с `rightPtr`, так как правее `rightPtr` все числа отсортированы (двойки).
