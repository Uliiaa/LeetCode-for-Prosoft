[**3895. Count Digit Appearances**](https://leetcode.com/problems/count-digit-appearances/)

Дан массив целых чисел `nums` и нужно посчитать общее количество вхождений заданной цифры `digit`. Я завела счетчик `counter`. Прошлась по всем числам массива и для каждого числа проверила цифры на совпадение с `digit` (если цифра совпала - инкрементировала счетчик). Цифры брала с помощью взятия остатка от деления на 10. Чтобы продолжать цикл "стирала" последнюю цифру числа с помощью целочисленного деления на 10.
